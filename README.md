# Inspiration — Scan. Read. Reflect. Lead.

A simple, beautiful web application for browsing and sharing inspirational quotes across six carefully curated categories.

## ✨ Features

- **6 Categories of Quotes**: Success, Leadership, Motivation, Resilience, Change & Adaptability, Teamwork & People
- **Random Quote Generator**: Click a category to get a random quote
- **One-Click Copy**: Easily copy quotes to share
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile
- **Accessible**: Built with ARIA labels and keyboard navigation support
- **Zero Dependencies**: Pure HTML, CSS, and JavaScript — no frameworks needed

## 🎯 How to Use

1. Visit the live site or open `index.html` locally in your browser
2. Browse quotes by clicking the category buttons
3. Click "Copy" to copy any quote to your clipboard
4. Scroll down to see all quotes in each category

## 🛠️ Customization

### Add New Quotes

Edit the `quotes` object in `index.html`:

```javascript
const quotes = {
  "YOUR_CATEGORY": [
    ["Quote text here", "Author name (optional)"],
    ["Another quote", "Author name"]
  ]
};
```

### Customize Colors

Update the CSS variables in the `<style>` section:
- `#071b2d` — Dark blue background
- `#b8860b` — Gold accent color
- `#ffffff` — White cards
